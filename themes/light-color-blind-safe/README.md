# Light Color-Blind Safe

Light Color-Blind Safe: the built-in light theme with folder, status and data type colors from the Okabe-Ito and Paul Tol palettes, distinguishable with deuteranopia, protanopia and tritanopia. Success and error are bluish green and vermillion instead of green and red.

## Install

Download [theme.json](https://raw.githubusercontent.com/antares-sql/themes/main/themes/light-color-blind-safe/theme.json), then in Antares open **Settings → Themes → Import from file**.
